SilverDecisions PeppVer (Pepperdine version, 2026)
A fork of SilverDecisions 1.2.1 maintained for decision-tree courses at the Pepperdine Graziadio Business School (Prof. James DiLellio; developed by Terren Chang).

It adds four optional settings under Settings → Options. All are off by default, so until you turn one on, the program behaves exactly like silverdecisions.pl and opens files saved there without change.

  • Show rollback values on decision and chance nodes: node values include the payoffs accumulated along the path from the root, the convention used in most decision-analysis textbooks.
  • Show computed payoffs in brackets: values computed by the program appear as [value], to tell them apart from values you typed.
  • Thicken only branches with 100% probability: only branches that are certain to be taken (chosen decision branches and 100% chance branches) are drawn thick; other chance branches on the optimal path stay thin.
  • Hide probabilities on terminal nodes: the probability-to-enter label is not drawn under terminal (triangle) nodes.

Source code and documentation: github.com/chat63791/SilverDecisionsPeppVer. The original project is at silverdecisions.pl; the text below is the original SilverDecisions About page.
